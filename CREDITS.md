# clack — Credits

clack's code is MIT licensed. The sound recordings come from the open-source projects below, and each pack ships with its upstream LICENSE file. GPL-licensed packs are distributed as separate data files and don't change clack's own license.

If you recorded one of these sounds and want the attribution corrected or the pack removed, open an issue at https://github.com/DarrylMathias/clack (a dedicated contact address is coming).
